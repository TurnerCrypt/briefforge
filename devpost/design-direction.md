# Visual direction

User request, 15 October 2026: minimalist multi-shape theme with screwdrivers, screws and other hackathon/building items. Reference images illustrate scattered outline doodles; create original artwork rather than copying their illustrations or arrangement.

Confirmed: minimalist presentation, varied maker/building shapes, original interpretation.

The learner accepted the first preview's visual direction and requested an Apple-like transparent feel on the large container and appropriate surfaces, distinctive button boxes, removal of the arrow, and a premium company-site finish.

Revised preview: charcoal backdrop, frosted translucent shell and secondary panels, subtle edge highlights, opaque input/result surfaces for reading, warm orange accent, tighter heading typography and an asymmetric clipped-corner Create checklist button. Both action arrows removed. The SVG simulates frosting with blurred artwork beneath the shell; the eventual browser implementation can use backdrop blur with an opaque fallback. Final revised appearance awaits learner feedback.

Original motifs: screwdriver, screw, hex nut, code brackets, terminal window, ruler, gear-like fastener and circuit traces. Keep pattern decorative, low contrast, and away from text.

Revision 3: learner requested a more randomized arrangement. The preview now uses 87 scattered motifs across a full-canvas pattern, with independently varied position, angle, size and opacity. Minimum spacing prevents accidental clutter; the smaller repeating grid was removed. Placement is deterministic so the design stays stable on reopening.

Core journey already approved: paste brief → review source-linked requirements and uncertainty flags → check off → export.

Still to resolve in product planning: first-screen layout, editing behavior, persistence and export format. No functional app or extraction engine exists yet.
